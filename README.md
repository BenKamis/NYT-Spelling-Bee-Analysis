A NYT spelling bee puzzle has 1 central letter and 6 other letters.
The central letter must be used in all found words.
Words must be 4 or more letter long and are worth points according to their lengths.
Every puzzle must have a pangram — a word that uses all 7 letters at least once each.

Using these rules and the 2019 Collins Scrabble Words dictionary, I found that there are a total of 146,888 possible puzzles.
I also generated a dictionary of every one of these puzzles, every word that can be found in each one, and what the maximum possible score is for each one.

Interesting data is shown in the histogram I generated and the statistics I pulled, which can be found at the end of the Jupyter Notebook file.
